# 掌中展开 · 数字剪纸（粒子版）

打开 `index.html` 就能运行（推荐用 GitHub Pages 的 https 网址，摄像头权限最顺）。没人时自动演示，把一只手举到镜头前就接管。

- 手势：举手 → 握拳 → 猛地张开 → 伸手指 1→5 → 捏住 → 捏着转手腕再松开；任何时候握拳停住 = 重来
- 计时（`src/main.js` 最上面的 `CFG`）：卡住 8 秒提示亮起；手离开 15 秒回到演示；有手但 60 秒没进展回到演示
- 键盘：D 演示/互动切换　H 隐藏文字　S 截图

文件：
- `src/main.js` 源码；`app.js` 是打包好的（改了源码需要重新打包）
- `tuanhua.js` 团花纹样；`guide.html` 手势指引卡（A4）
- `sound/compose.py` 声音样片的合成脚本（还没接进作品）
- `particles.html` 分镜静帧；`preview/` 预览图和演示录屏
